# 程式製作產品概念廣告

整支影片（3D 模型、材質、燈光、運鏡、螢幕畫面、字卡、配樂）全部由程式產生，不用 AI 生圖或生影片。流程整理自使用者提供的《程式做iPhone廣告_完整流程》PDF。

## 開始前先問清楚（缺的才問）
- 主題／產品、片長（PDF 範例：90 秒、24 鏡）、橫式或直式
- 外型參考圖或官網連結（官方沒公布尺寸時，外型要對照照片推估）
- 規格資料來源（官網、新聞稿）

## 環境
先執行 `scripts/check_env.sh` 檢查；缺什麼再裝，不要一次全裝。需要：
Blender（PDF 用 5.2）、Python 3（numpy、scipy、opencv-python、Pillow）、Node.js + Puppeteer + Chrome、ffmpeg。
渲染所需時間與記憶體依機器而異（PDF 作者：M4 Pro / 24GB，24 鏡約 2 小時，兩個 Blender 並行）。先用實測決定並行數，不要假設。

## 7 步流程
1. **查規格、寫分鏡**：查官方資料，整理規格；寫成分鏡表（每鏡秒數、畫面、字卡）。字卡上每個數字都要對得到官方原句。**分鏡必須給使用者確認後才開始渲染**（渲染很耗時，邊做邊改浪費）。
2. **共用時間軸**：一個檔案記錄每鏡起訖秒、轉場、重拍落點。畫面、配樂、字卡都讀這份。配樂用固定 BPM（PDF：120），剪點自然落在鼓點。
3. **3D 模型與材質**：用 Python 控制 Blender 從零建模；金屬、玻璃、螢幕、鏡頭鍍膜各寫一個材質；Logo 用幾何拼出，不下載圖檔；攝影棚燈光（反光板）也用程式建立。
4. **螢幕畫面**：先用 HTML 做成動畫 → Puppeteer 開 Chrome 逐格截圖 → 貼到 3D 螢幕貼圖上隨鏡頭運動。
5. **運鏡與渲染**：每鏡攝影機位置用函式計算並逐格打關鍵格（推、拉、繞拍、俯拍、翻面、拉焦）。Blender EEVEE 背景渲染、不開介面。
6. **配樂與音效**：不使用音檔，全用 numpy 從波形合成（大鼓、拍手、hi-hat、riser、whoosh、pad、bass、琶音、快門聲），加殘響、延遲、側鏈壓縮、限幅。畫波形與頻譜，確認重拍落在剪點。
7. **合成輸出**：畫面放黑底，加光暈、暗角、細顆粒；轉場用淡入、閃白、黑場；字卡淡入、上浮、模糊變清晰；ffmpeg 輸出 H.264 + AAC 的 MP4。

## 工作規則
- 先出低解析度預覽或少數鏡頭（例如 3 鏡）驗證整條流程，再全量渲染。
- 渲染放背景跑，避免被中斷。
- 使用者提修改意見時，請他指出哪一秒、哪裡不對、要改成怎樣；你自己的回報也要具體到鏡頭編號。
- 影片結尾或說明須標註「概念影片，非官方作品」；不使用官方商標圖檔。
